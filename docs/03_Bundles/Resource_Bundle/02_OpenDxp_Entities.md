# Adding a New OpenDxp Entity with Class Installation

There are multiple ways to add a new OpenDxp Entity to CoreShop. This guide will show you 3 different ways:

 - For Bundles that take advantage of the CoreShop Resource Bundle: [OpenDxp Entities for Bundles](03_OpenDxp_Entities_for_Bundles.md)
 - For Projects using the Resource Config: [OpenDxp for Projects using Resource Config](05_OpenDxp_Entities_for_Projects_using_Resource_Config.md)
 - For Projects using the `AsOpenDxpModel` Attribute: [OpenDxp for Projects using AsOpenDxpModel Attribute](04_OpenDxp_Entities_for_Projects_using_AsOpenDxpModel_Attribute.md)
